Citation
========

Thanks for using CMLM!

Software
~~~~~~~~

To cite the use of this piece of software, cite the corresponding `NREL software record <https://doi.org/10.11578/dc.20240508.3>`_:

.. code-block:: none

   Perry, Bruce, Yellapantula, Shashank, Henry de Frahan, Marc, & Eiden, Kiran (2024). CMLM (Co-Optimized Machine-Learned Manifolds) [SWR-23-41]. https://doi.org/10.11578/dc.20240508.3

.. code-block:: bibtex

   @misc{osti_code-122681,
      author = {Perry, Bruce and Yellapantula, Shashank and Henry de Frahan, Marc and Eiden, Kiran},
      title  = {CMLM (Co-Optimized Machine-Learned Manifolds) [SWR-23-41]},
      doi    = {10.11578/dc.20240508.3},
      url    = {https://www.osti.gov/biblio/code-122681},
      place  = {United States},
      year   = {2024},
      month  = {02}
  }

Model
~~~~~

To cite the use of the CMLM model or related neural network structures, use the `Combustion and Flame paper <https://doi.org/10.1016/j.combustflame.2022.112286>`_ in which is was first published:

.. code-block:: none

   Perry, B. A., de Frahan, M. T. H., & Yellapantula, S. (2022). Co-optimized machine-learned manifold models for large eddy simulation of turbulent combustion. Combustion and Flame, 244, 112286.

.. code-block:: bibtex

   @article{perry2022co,
       title     = {Co-optimized machine-learned manifold models for large eddy simulation of turbulent combustion},
       author    = {Perry, Bruce A and de Frahan, Marc T Henry and Yellapantula, Shashank},
       journal   = {Combustion and Flame},
       volume    = {244},
       pages     = {112286},
       year      = {2022},
       publisher = {Elsevier}
   }
